                    牧场动物大作战（Prototype 2）
                              README
======================================================================

一、项目简介
----------------------------------------------------------------------
这是一个使用 Unity 制作的俯视角射击小游戏。

玩家控制角色在场地底部左右移动，按住空格连续发射食物。
鸡、鹿、狗会从场地远处向玩家靠近，玩家需要在它们碰到自己之前
用食物把它们击倒。

游戏包含 5 个难度逐渐提高的关卡。每只动物都有独立血量，
动物头顶会显示血条，击杀动物可以获得分数。

项目名称：My project (1)
场景名称：Prototype 2
Unity 版本：2022.3.62f3c1
游戏类型：单场景、俯视角、射击、关卡挑战


二、运行方式
----------------------------------------------------------------------
1. 使用 Unity Hub 打开项目目录：
   C:\unity.lly\My project (1)

2. 使用 Unity 2022.3.62f3c1 打开项目。

3. 打开场景：
   Assets/Resources/Scenes/Prototype 2.unity

4. 点击编辑器顶部的 Play 按钮开始游戏。

说明：
- 该场景已经加入 Build Settings，可以直接打包。
- 进入 Play 后，关卡系统会自动挂到 Canvas 上，不需要手动拖拽组件。
- HUD（关卡、击杀进度、分数、操作提示）由代码在运行时生成。
- 如果修改脚本后 Unity 没有自动刷新，切回 Unity 按 Ctrl + R，
  等待编译完成后再点击 Play。


三、操作方式
----------------------------------------------------------------------
A / D 或 ← / →    左右移动
按住空格           连续发射食物
鼠标左键           点击结算界面上的“下一关”“重试本关”“退出游戏”等按钮

手机 / 网页版：
- 左下角“左”“右”按钮：按住移动。
- 右下角“射击”按钮：按住连续发射。
- 结算界面的按钮已加大，方便手指点击。
- WebGL 版点击“打开主页”会打开 https://66yanggg.github.io；
  Windows exe 点击“退出游戏”会正常退出程序。

补充说明：
- 玩家活动范围约为 X = -17 到 X = 17。
- 射击有 0.14 秒冷却，按住空格即可连续射击。
- 游戏输入使用的是 Unity 旧版 Input Manager（Horizontal / Space）。


四、游戏规则
----------------------------------------------------------------------
1. 玩家初始有 3 颗心。
2. 动物撞到玩家时，玩家失去 1 颗心。
3. 玩家受伤后有 1.1 秒无敌时间，期间不会再次扣血。
4. 3 颗心全部耗尽时本关失败，可以点击“重试本关”。
5. 击杀数量达到本关目标后过关。
6. 第 1 到第 4 关完成后，点击“下一关”继续。
7. 第 5 关完成后显示“全部关卡通关！”，可以点击“再玩一次”重新开始。
8. 每通过一关，玩家血量会恢复满，分数会保留到下一关。
9. 重试本关时，分数会回到进入本关时的分数，避免重复刷分。
10. 每关开始时，上一关剩余的动物和食物会被清理。

得分规则：
- 每击杀一只动物，获得 10 + (动物最大血量 - 1) × 5 分。
  例如：1 血动物 = 10 分，2 血动物 = 15 分，4 血动物 = 25 分。
- 每通过一关，额外获得 50 分过关奖励。
- 分数会显示在画面右上角，击杀进度会显示在画面顶部。


五、五关配置
----------------------------------------------------------------------
关卡   名称       目标击杀   动物血量   出怪间隔   速度倍率   同屏上限   鸡/鹿/狗比例
----   --------   --------   --------   --------   --------   --------   ------------
 1     牧场热身      8         1        1.50 秒     0.60        6        100 / 0 / 0
 2     鸡飞狗跳     10         2        1.30 秒     0.72        7         65 / 20 / 15
 3     森林来客     12         2        1.15 秒     0.85        8         40 / 40 / 20
 4     猎手试炼     15         3        1.00 秒     0.98       10         25 / 45 / 30
 5     终极围猎     18        3 ~ 4     0.85 秒     1.10       12         15 / 45 / 40

说明：
- 速度倍率会乘到动物预制体原本的速度上。
  鸡的基础速度约为 3，鹿约为 8，狗约为 5。
- 随着关卡提高，目标击杀数、动物血量、出怪频率、同屏数量和
  高血量动物的比例都会增加，所以难度是逐步上升的。
- 同一关卡内，动物的具体血量会在 minHp 到 maxHp 之间随机。


六、动物血量系统
----------------------------------------------------------------------
每只动物生成时都会获得一个 AnimalHealth 组件，并由 LevelManager
注入本关的血量。

- 第 1 关：动物 1 血。
- 第 2、3 关：动物 2 血。
- 第 4 关：动物 3 血。
- 第 5 关：动物 3 或 4 血。

血条：
- 每只动物头顶会生成一个世界空间血条。
- 满血或血量较高时显示绿色。
- 血量中等时显示黄色。
- 血量较低时显示红色。
- 动物死亡后血条会立即隐藏并销毁。

伤害与死亡：
- 玩家发射的食物默认造成 1 点伤害。
- 食物命中动物后自身销毁，动物扣血。
- 动物血量降到 0 或以下时死亡。
- 死亡时播放缩放 / 旋转消失效果，并播放击杀音效。
- 动物撞到玩家、或从场景后方跑出时，会以“非击杀”的方式消失，
  不会给玩家加分。


七、游戏流程
----------------------------------------------------------------------
开始游戏
  ↓
第 1 关 → 击杀达标 → 过关结算 → 下一关
  ↓                              ↑
第 2 关 → 击杀达标 → 过关结算 ──┘
  ↓
第 3 关 → 击杀达标 → 过关结算
  ↓
第 4 关 → 击杀达标 → 过关结算
  ↓
第 5 关 → 击杀达标 → 最终结算（全部通关）
  ↓
再玩一次 → 回到第 1 关

任意关卡中玩家 3 颗心耗尽：
  ↓
失败结算 → 重试本关 → 重新开始当前关卡

结算界面按钮：
- 第 1~4 关完成：“下一关”
- 第 5 关完成：“再玩一次”
- 失败：“重试本关”
- “退出游戏”：编辑器中停止 Play；Windows exe 退出程序；
  WebGL 版本显示为“打开主页”，点击打开 https://66yanggg.github.io

九、如何调整难度
----------------------------------------------------------------------
打开：
  Assets/Resources/LevelManager.cs

找到 CreateDefaultLevels() 方法，修改每一关的 LevelDefinition 字段：

  displayName      关卡显示名称
  targetKills      本关需要击杀的动物数量
  spawnInterval    出怪间隔（秒），越小出怪越快
  firstSpawnDelay  关卡开始后第一只动物的延迟
  speedMultiplier  动物速度倍率，越大移动越快
  minHp / maxHp    动物血量范围
  maxAlive         同屏最多存在多少只动物
  chickWeight      鸡的生成权重
  deerWeight       鹿的生成权重
  dogWeight        狗的生成权重

例如想让第 1 关更简单：
- 把 targetKills 从 8 改成 5
- 把 spawnInterval 从 1.50 改成 2.00
- 把 maxAlive 从 6 改成 4

如果想增加第 6 关：
- 在 levels 数组末尾再添加一个 LevelDefinition
- HUD 会自动显示“第 X / 6 关”
- 第 6 关会成为新的最终关

也可以手动在场景的 Canvas 上添加 LevelManager 组件，
然后在 Inspector 中直接编辑 levels 数组。
注意：一旦手动挂载，代码会优先使用这个组件上的配置。


十、脚本优化说明
----------------------------------------------------------------------
相比最初的原型，本版本做了以下优化：

1. GameFacade 缓存 GameController、LevelManager、SoundController
   和资源工厂，避免在运行时反复 Find / GetComponent。

2. ProxyAssetFactory 缓存“预制体资源”，而不是缓存已经实例化的对象。
   这样可以安全地重复生成动物和食物，不会在场景里留下多余的模板实例。

3. ResourcesAssetFactory 缓存 Resources.Load 的结果，
   减少重复加载磁盘资源。

4. EnemyController 缓存 Transform 和基础速度；
   动物使用 kinematic 刚体，不会因为互相碰撞而翻倒或被推走。

5. 鹿和狗原本的 BoxCollider 过小，食物容易打不中。
   EnemyController 会根据模型的 Renderer 包围盒自动重设碰撞体，
   让命中判定和视觉模型一致。

6. 玩家脚本缓存 Renderer、Rigidbody；
   加入射速冷却、连续射击、受击闪烁和无敌帧。

7. 食物使用无重力刚体，避免下坠；生成时忽略与玩家自身的碰撞，
   防止刚发射时被玩家自己的碰撞体弹开。

8. 动物血量使用事件通知关卡系统，不需要每帧查找或轮询动物列表。

9. HUD 只在游戏开始时生成一次，之后每关开始显示、结算时隐藏，
   避免每帧创建 UI 对象。


十一、常见问题
----------------------------------------------------------------------
Q1：点击 Play 后没有动物或没有 HUD？
A：关卡开始后约 1.2 秒才会生成第一只动物；请稍等。
   如果仍然没有，检查 Console 是否有报错，按 Ctrl + R 重新导入，
   并确认场景里有 Canvas、GameController 和 GameFacade。

Q2：在编辑模式看不到 LevelManager？
A：LevelManager 是在运行时自动添加到 Canvas 上的，所以编辑模式下
   不会出现在场景里。进入 Play 后可以在 Hierarchy 的 Canvas 上看到它。
   也可以手动添加一个 LevelManager 组件来在 Inspector 里调参。

Q3：中文显示成方框？
A：运行时会优先使用 Windows 的“Microsoft YaHei”字体，
   如果没有该字体则回退到 Arial。某些非 Windows 平台可能缺少中文字体，
   可以在 GameController.ResolveFont() 中替换成项目自带的中文字体。

Q4：没有声音？
A：检查场景 Main Camera 上是否有 AudioListener，
   检查 GameFacade 所在物体上是否有 Soundcontroller 组件，
   并确认 Unity 编辑器的 Mute Audio 没有开启。

Q5：食物打不中动物？
A：确认动物预制体上有 Collider 和 EnemyController；
   本版本会自动根据模型重设碰撞体，一般不需要手动调整。
   另外，食物是从玩家位置向 +Z 方向飞行的，动物需要位于玩家前方。

Q6：如何重新开始整个游戏？
A：在第 5 关的最终结算界面点击“再玩一次”，
   或者在 Play 模式下重新加载场景。

Q7：游戏进度会保存吗？
A：当前版本是单次游戏流程，不保存关卡进度；
   停止 Play 后会从第 1 关重新开始。
